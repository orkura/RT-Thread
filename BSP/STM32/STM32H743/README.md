# 多通道压力采集器

本项目基于 STM32H743 和 RT-Thread，实现多通道气压采集、数据存储、对外通信及低温环境下的板级温度控制。

## 主要功能

1. **压力采集**：通过板载 20 个压力传感器采集外界气压。
2. **数据存储**：将采集的压力数据存储到 SD 卡或板载 Flash 芯片。
3. **RS-422 通信**：通过板载 RS-422 接口向外部设备发送采集的压力数据。
4. **低温温控**：在低温环境下，利用温度传感器监测板子温度，并调节板载可调电源，实现板级温度控制。
5. **CAN 通信**：通过板载 CAN 接口与外部设备通信，用于压力数据传输及设备交互；当前软件已接入 FDCAN2 和 CANopenNode，具体业务数据映射随应用开发完善。
